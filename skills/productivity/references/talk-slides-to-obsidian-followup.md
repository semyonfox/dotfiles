# Talk slides to Obsidian follow-up note

Use this when an email or networking follow-up references a talk, workshop, conference, or slide deck and Semyon wants the useful bits saved into Obsidian.

## Pattern

1. Fetch/export the source material when available. For public Google Slides, try:
   - `https://docs.google.com/presentation/d/<ID>/export/txt`
2. Search the Obsidian vault for the relevant conference or topic first.
3. Put the new note near the strongest existing context, not in a random scratch folder.
   - Example: a Portershed funnel workshop can live beside WebExpo funnel summaries if it directly relates to the same SaaS funnel material.
4. Link to existing notes rather than duplicating all content.
5. Write a concise synthesis focused on Semyon's actual project and next actions.
6. Update the local index note if the directory has one.
7. Verify the new note and index with readback.

## Content shape

- Frontmatter with `title`, `event`, `type`, `speaker`, `source`, `related`, and tags.
- `Useful takeaway` section.
- Practical project-specific application section.
- Checklist of next actions.
- Links to related conference/source notes.

## Pitfalls

- Do not imply the project is launched if it is pre-launch.
- Do not make a polished generic conference summary when Semyon wants actionable notes.
- Do not scatter one-off notes into the vault root if a conference/project folder already exists.
