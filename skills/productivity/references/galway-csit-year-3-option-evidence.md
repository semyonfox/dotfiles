# University of Galway CSIT third-year option evidence

## Scope

This is a condensed evidence bank for future academic-option conversations with Semyon. It is not a substitute for the cohort-specific handbook, Canvas page, timetable, or registration system.

## Programme structure observed

For the University of Galway CSIT third year, the published programme material previously showed **two 5-ECTS options** (10 ECTS total) selected from:

- CT318 — Human-Computer Interaction
- CT331 — Programming Paradigms
- CT3536 — Games Programming
- MA341 — Metric Spaces
- MA385 — Numerical Analysis I
- MA3343 — Groups
- PI315 — Philosophy of Mind

The teaching semester before placement is unusually concentrated. Treat workload and assessment shape as first-class decision criteria, not only subject interest.

## User-specific provisional decision

The evidence-supported pairing was **CT318 + CT3536**. CT331 remains the alternate only if Semyon deliberately prefers theory/foundations and will pre-train Lisp/Prolog, recursion, and timed written answers.

## Revalidation checklist

Before registration or treating any detail as final:

1. Open the **current official module records** (`https://www.universityofgalway.ie/course-information/module/CT318`, `/CT331`, `/CT3536`) and record credits, semester, prerequisites and assessment components.
2. Check the current handbook/Canvas pages for exact CA briefs, group/individual rules, practical demo requirements, lecturer changes and module availability.
3. Check timetable clashes and placement/semester credit concentration.
4. Use historical GitHub projects and old papers only as evidence of likely skills/assessment surface, never as a promise of the current assignment.
5. If papers become available, compare at least two per candidate for recurring topics, marks distribution, memorisation load and timed code-writing burden.
