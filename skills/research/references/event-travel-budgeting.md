# Event travel budgeting notes

Use this when estimating whether an event trip is feasible within a user budget.

## Pattern
1. Verify the event facts from the official page first: dates, city/venue area, whether admission is free/paid/selective, and any travel credit/reimbursement language.
2. Pick dates that actually satisfy the user's trip shape, not just the event dates. For a 2-day event plus 1 sightseeing day, usually price: arrive the day before, attend both days, sightsee the day after, fly home after that.
3. Price the user's preferred airports first, then the fallback airport. For Ireland-to-long-haul requests, compare Shannon/Knock if requested, but also Dublin because it often has cleaner routings.
4. Separate:
   - flight fare
   - accommodation
   - food/local transit/sightseeing padding
   - event admission
   - optional travel credit/reimbursement
5. Present both "barebones" and "realistic all-in" totals. Users often ask for a target band like €600-€1k; answer whether the band is possible before listing details.

## Budgeting heuristics
- For hostel-style trips, use dorm prices plus a tax/fees buffer rather than treating headline nightly prices as final.
- If an event offers a flight credit, show cost before and after the credit, and state that reimbursement may not reduce upfront cash needed.
- Do not recommend absurd itineraries just because they are technically cheapest. Flag self-transfer, very long duration, overnight layovers, or multi-day trips as "cheap but cursed".
- If the cheapest route is poor and a slightly higher route is much cleaner, call out the practical option.

## Output shape
- Start with a direct yes/no on feasibility.
- Include a compact table by airport/route.
- Mention event admission separately.
- End with a recommendation, not just raw prices.

## Session-derived example
For YC Startup School 2026, useful facts were: official page said San Francisco, July 25-26, selective attendance, free to attend, and limited $500 flight credits for accepted attendees outside the Bay Area. A sensible Ireland itinerary for event + 1 sightseeing day was July 24-28. Kiwi visible results gave comparable DUB/SNN/NOC fares, while hostel sources gave a rough dorm-bed accommodation range. The actionable answer was that €600-€1k all-in was only realistic with the $500 flight credit; otherwise the barebones floor was just over €1k.
