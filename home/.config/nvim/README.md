# Neovim

LazyVim-based Neovim configuration.

## Included

- LazyVim starter layout
- Catppuccin Mocha colorscheme
- Transparent background highlights
- Neo-tree extra enabled through `lazyvim.json`
- Relative line numbers disabled
- Snacks animated scrolling disabled

## Notes

The old all-themes bundle and inert LazyVim starter example were removed. Add individual colorschemes back only when they are actually used.
